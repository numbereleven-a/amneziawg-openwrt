# Правила локальной сборки AmneziaWG для MediaTek Filogic

Этот документ описывает воспроизводимую сборку пакетов из данного репозитория. Он относится только к указанным ниже версиям прошивки, цели и архитектуре.

## Поддерживаемые цели

| Прошивка | Релиз SDK | Цель | Архитектура | Ожидаемый ABI ядра |
| --- | --- | --- | --- | --- |
| OpenWrt 24.10.1 | `r28597-0425664679` | `mediatek/filogic` | `aarch64_cortex-a53` | `6.6.86~6ace983a14b769f576fe9c4c7961bd89-r1` |
| OpenWrt 23.05.5 | `r24106-10cc5fcd00` | `mediatek/filogic` | `aarch64_cortex-a53` | `5.15.167-1-03ba5b5fee47f2232a088e3cd9832aec` |

`kmod-amneziawg` жёстко привязан к ABI ядра. Пакет, собранный для одной строки таблицы, нельзя устанавливать на другую версию OpenWrt, другую цель или прошивку с иным ABI, даже если архитектура процессора совпадает.

## Обновление исходников

1. Для версии AmneziaWG использовать конкретный upstream-тег и зафиксированные коммиты исходных репозиториев, а не их ветку `master`.
2. Сверить с выбранным upstream-тегом `PKG_VERSION`, `PKG_SOURCE_VERSION` и контрольные суммы в Makefile пакетов:
   - `kmod-amneziawg/Makefile`;
   - `amneziawg-tools/Makefile`;
   - `amneziawg-go/Makefile`;
   - `luci-proto-amneziawg/Makefile`.
3. Обновить переменную версии в `.github/workflows/build-filogic-release.yml`.
4. Выполнить `git diff --check` и проверить, что изменение версий не затронуло посторонние файлы.
5. Ссылки на выпуск в README менять только после фактической публикации соответствующего архива.

## Среда сборки

- Использовать отдельный чистый каталог для каждой комбинации версии AmneziaWG и SDK. Не смешивать результаты 23.05.5 и 24.10.1.
- Работать в постоянной файловой системе Linux; временные системные каталоги не использовать для SDK и результатов сборки.
- Предпочтительная среда — Ubuntu 24.04 или совместимая система с GNU coreutils и GCC/G++ 13. Компиляторы должны быть доступны как `cc` и `c++`.
- До запуска установить обычные зависимости SDK, включая Python с `pyelftools`, SWIG, компилятор C/C++, `make`, Git, `curl`, `tar` и `zstd`.
- Если для получения исходников требуется прокси, задавать его только переменными окружения процесса сборки. Не сохранять адреса прокси, учётные данные или локальные настройки в репозитории.
- Загружать только официальный SDK точной версии из таблицы и использовать его `config.buildinfo` без изменений цели, архитектуры или конфигурации ядра.

## Порядок сборки

1. Распаковать SDK и применить его `config.buildinfo`:

   ```sh
   cp config.buildinfo .config
   make defconfig
   ```

2. Добавить этот репозиторий как локальный feed, затем обновить и установить feeds штатными скриптами SDK:

   ```sh
   printf '%s\n' 'src-cpy amneziawg /path/to/amneziawg-openwrt' >> feeds.conf.default
   ./scripts/feeds update -a
   ./scripts/feeds install -a
   ```

3. Собрать пакеты по отдельности. Перед повторной попыткой очищать только пакет, который требуется пересобрать:

   ```sh
   make package/kmod-amneziawg/{clean,download,prepare,compile} -j"$(nproc)"
   make package/amneziawg-tools/{clean,download,prepare,compile} -j"$(nproc)"
   make package/luci-proto-amneziawg/{clean,download,prepare,compile} -j"$(nproc)"
   ```

4. Взять файлы из `bin/packages/<arch>/amneziawg/`. В набор должны входить ровно четыре IPK:

   - `kmod-amneziawg`;
   - `amneziawg-tools`;
   - `luci-proto-amneziawg`;
   - `luci-i18n-amneziawg-ru`.

## Обязательная проверка результата

Перед созданием архива для каждой цели проверить следующее:

- версии пакетов соответствуют выбранной версии AmneziaWG;
- поле `Architecture` у модуля и утилит — `aarch64_cortex-a53` либо эквивалентное имя архитектуры SDK; LuCI-пакеты могут иметь `all`;
- в `Depends` пакета `kmod-amneziawg` присутствует точный ABI ядра из таблицы;
- набор содержит все четыре IPK и не содержит логов, исходников SDK, временных файлов или посторонних пакетов;
- контрольные суммы всех IPK успешно проверяются командой `sha256sum -c SHA256SUMS`.

В `build-info.txt` архива обязательно указать версию AmneziaWG, версию SDK, цель, архитектуру и ABI ядра, извлечённый из поля `Depends` у собранного `kmod-amneziawg`.

После упаковки проверить архив и его отдельный файл `.sha256`:

```sh
sha256sum -c amneziawg-<version>-mediatek-filogic-aarch64_cortex-a53-openwrt-<release>.tar.gz.sha256
tar -tzf amneziawg-<version>-mediatek-filogic-aarch64_cortex-a53-openwrt-<release>.tar.gz
```

## Подготовка к публикации

В выпуск включать только архив пакетов и соседний файл `.sha256`. До публикации повторно проверить содержимое архива, отсутствие секретов, локальных путей, прокси-настроек и служебных журналов. Старые выпуски и их артефакты не удалять.

Коммит, отправка изменений и публикация релиза выполняются только после отдельного подтверждения владельца репозитория.
